## 📖 关于这个博客

这个博客主要记录我的学习、研究以及一些日常思考。

你可以在这里访问：

- 一些 **计算机技术相关文章**
- **算法、系统、AI、编程相关笔记**
- 偶尔的 **日常碎碎念**

需要说明的是：

- **日常碎碎念部分**可能包含个人观点，我不能完全保证其客观性。
- **技术性博客部分**会尽量保持严谨，并经过一定程度的验证。

技术文章通常会进行以下检查：

- 🔎 **溯源（Source tracing）**
- 📚 **多来源对比（Cross-source comparison）**
- ✔ **逻辑校验（Logical verification）**
- 🧪 **可复现性测试（Reproducibility testing）**

我的目标是尽可能让技术内容 **清晰、可靠、可复现**。
